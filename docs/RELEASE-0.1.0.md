Pierwsze wydanie Codex Monitor dla Windows.

- Instalator dla bieżącego użytkownika (około 2,2 MB), z polskim interfejsem i deinstalacją.
- Ikona w zasobniku pokazuje zużycie limitów Codex i odświeża dane co 5 minut.
- Wymaga .NET 10 Desktop Runtime (x64). Jeśli brakuje `codex-cli-usage`, aplikacja umożliwia instalację przez `uv`.
